# Changelog - 2026-03-01

## [010] Multi-Container & Strategy Logic
- Implemented `MultiContainerEngine` to handle items that exceed a single container's capacity.
- Added two optimization strategies:
    - **Minimize Items Out**: Fills the primary space first, then places the rest in an overflow container.
    - **Suggest Additional Space**: Calculates a custom-sized secondary space to minimize "criticity" (waste).
- Updated FastAPI `/pack` endpoint to support multi-container results and strategy selection.
- Enhanced `viewer.html` with:
    - Custom container and item inputs.
    - Strategy and Engine selection.
    - Container navigation UI (Prev/Next) for visualizing multiple bins.
- Verified end-to-end workflow from UI to multi-container packing.
