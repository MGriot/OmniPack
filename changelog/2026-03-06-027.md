# Changelog - 2026-03-06

## [027] Optional Feature Toggles (API & Logic) (Verified)
- Added global toggles `enable_mixing`, `enable_strategy`, and `enable_rotation` to `PackingRequest`.
- Updated `ItemInput` to allow optional per-item mixing overrides.
- Refined packing logic in `main.py` to enforce global restrictions:
    - `enable_rotation=False` forces default orientation for all items.
    - `enable_strategy=False` disables FIFO/LIFO sequences.
    - `enable_mixing=False` forces grouping by item ID or group ID.
- Maintained backward compatibility with existing API clients.
