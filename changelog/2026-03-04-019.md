# Changelog - 2026-03-04

## [019] Enhanced Item Mixing (GRASP Heuristic)
- Updated `core/engine_v2.py`:
    - Implemented **GRASP (Greedy Randomized Adaptive Search Procedure)** in `Level2Engine.pack`.
    - Added `grasp_k` parameter to control the size of the **Restricted Candidate List (RCL)**.
    - Instead of always picking the single best position, the engine now picks randomly from the top $k$ candidates, enabling diverse packing layouts.
- Updated `core/multi_container.py`:
    - Passed `grasp_k` parameter through `MultiContainerEngine` to the underlying calculation cores.
- Updated `main.py`:
    - Added `strategy` and `stop_id` to `ItemInput` API model.
    - Added `grasp_k` to `PackingRequest` API model.
    - Integrated new parameters into the scenario generation loop.
- Verified with `tests/test_grasp.py`:
    - Confirmed that $k=1$ is deterministic.
    - Confirmed that $k>1$ produces diverse packing results for the same input set.
- Updated tracking files (`tasks.json`, `stage.md`).
