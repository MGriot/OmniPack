# Changelog - 2026-03-04

## [017] FIFO/LIFO Packing Logic
- Updated `core/models.py`:
    - Added `LoadingStrategy` enum (NONE, FIFO, LIFO).
    - Added `strategy` field to `Item` model.
- Updated `core/engine_v2.py`:
    - Modified item sorting to prioritize LIFO, then FIFO, then NONE.
    - Updated `Level2Engine` to seed both Back (`Z=0`) and Front (`Z=Depth`) Extreme Points.
    - Implemented directional scoring: LIFO items prefer high Z, FIFO items prefer low Z.
    - Added a "Backward Testing" loop for LIFO items to allow placement ending at an Extreme Point.
- Updated `core/ep.py`:
    - Enhanced `generate_extreme_points` to support backward projection (LIFO).
    - Modified boundary checks to allow points at `Z=Depth`.
- Updated `core/accelerated.py`:
    - Relaxed stability checks for LIFO items placed at the very front of the container (door support logic).
- Verified with `tests/test_fifo_lifo.py`:
    - FIFO items correctly placed at the back (`Z=0`).
    - LIFO items correctly placed at the front (`Z=80` for depth 20 item in 100 depth bin).
- Updated tracking files (`tasks.json`, `stage.md`).
