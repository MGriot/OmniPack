# Changelog - 2026-03-01

## [005] Level 1 Engine - Best-Fit Decreasing
- Implemented `Level1Engine` class.
- Added Best-Fit Decreasing (BFD) heuristic:
    - Sorts items by volume descending.
    - Tests all 6 rotations for each item.
    - Picks the best Extreme Point (Bottom-Left-Back priority).
- Implemented `pack_items` utility function.
- Added comprehensive tests in `tests/test_engine.py` covering basic packing, automatic rotation, and overflow handling.
- Verified engine with `pytest`.
