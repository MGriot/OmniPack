# Changelog - 2026-03-01

## [011] Weight & Stacking Constraints
- Added `weight` and `max_stack_weight` to the `Item` model.
- Updated `evaluate_positions_parallel` in `core/accelerated.py` to enforce stacking limits:
    - Detects if an item is placed directly on top of another.
    - Validates that the new item's weight does not exceed the supported weight of the base item.
- Updated `Level2Engine` to pass weight arrays to the JIT evaluator.
- Enhanced the FastAPI `ItemInput` model to accept weight parameters.
- Enhanced `viewer.html` with:
    - Weight and Max Top Support inputs for each item type.
    - Total packed weight reporting in the stats UI.
    - Visual indicators for heavy items.
- Verified that fragile items (low `Max Top`) trigger overflow logic if weight is exceeded.
