# Changelog - 2026-03-01

## [012c] Strict Floor-First Packing Constraint
- Upgraded `evaluate_positions_parallel` in `core/accelerated.py` with a **Two-Pass Validation** strategy:
    - **Pass 1**: Scans all available Extreme Points for floor-level placements (`Z=0`).
    - **Pass 2**: If *any* floor spot is valid for the current item, **all stacking positions** (`Z>0`) are explicitly marked as invalid.
- Effect: The engine is now physically prevented from stacking items as long as a valid floor position exists for that item, regardless of the scoring strategy.
- Maintained all existing physics rules (CoG, weight transfer) for scenarios where stacking is unavoidable (floor is full).
- Improved **Extreme Points Projection** to discover more floor gaps between existing items.
